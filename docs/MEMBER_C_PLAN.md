## 样例验证方式

`tests/files/verify_samples.py` 在没有 GUI 的情况下复现应用的导出路径：

`FormatXmlSchematic::load` → 按几何重建网表 → `FormatSpice::generateNetlist` → ngspice

实现要点与源码保持一致：属性采用"库默认值 + 工程覆盖"的合并顺序（对应 `Component::setComponentData`），`%label`/`%port`/`%property`/`%model`/`%directive` 的展开遵循 `docs/modelsformat.h` 的规范，模型与指令按出现顺序去重后追加到文件末尾。

```sh
python3 tests/files/verify_samples.py --ngspice ngspice
```

RC 样例的检查点是有限上升沿的闭式解，整流样例是 ngspice-47 实测值。这条路径只验证"样例仍能生成正确网表并仿真"，不能替代 HAP 内的 UI 验收。
